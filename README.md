# 🎭 Medici Synapse - 跨域创新引擎

> **"The Medici Synapse is a cross-domain innovation engine that refuses linear extrapolation. It seeks 'Structural Isomorphism' between entirely unrelated domains."**

## 🌟 核心理念

Medici Synapse 不是简单的创意生成器，它是一个**结构同构性映射引擎**。它：

- ❌ **拒绝**: A + B 的简单加法（例如：咖啡 + 量子 ≠ 量子咖啡）
- ✅ **追求**: 将领域 A 的底层法则暴力移植到领域 B 的商业场景

## 🚀 如何使用

### 基本用法

在 Claude Code 中运行：

```
/medici-synapse
```

然后输入任意两个领域，例如：
- **游戏开发** + **世界模型**
- **火锅店** + **赛博朋克黑客技术**
- **咖啡连锁** + **量子力学**

### 输出内容

Medici Synapse 会生成一份完整的创新 Pitch Deck，包括：

1. **🧬 基因提取**: 拆解两个领域的核心法则与痛点
2. **🚀 创新概念**: 具有未来感的项目名称、Slogan 和详细机制
3. **💼 商业逻辑**: 价值主张、盈利模式、目标用户
4. **⚠️ 风险与护城河**: 技术风险、市场竞争优势分析
5. **🛣️ MVP 路线图**: 可执行的阶段性实施计划

## 📖 核心方法论

### The Abstraction-Mapping Protocol

```
领域 A (概念源)         领域 B (应用场景)
    ↓                        ↓
第一性原理拆解    →    商业痛点提取
    ↓                        ↓
    ┅━━━━━━━━━━━━━━━━━━━━━━┅
              ↓
      强制结构映射
    (Forced Mapping)
              ↓
    ┅━━━━━━━━━━━━━━━━━━━━━━┅
              ↓
      颠覆性创新方案
              ↓
      商业闭环构建
```

### 三大阶段

1. **Deconstruction (拆解)**
   - 提取领域 A 的 3-5 个核心法则/机制
   - 提取领域 B 的 3-5 个商业痛点/环节

2. **Forced Mapping (强制映射)**
   - 将 A 的法则作为解决 B 的方案
   - 寻找结构同构性，而非表面相似性

3. **Synthesis (综合)**
   - 构建商业逻辑闭环
   - 分析风险与护城河

## 🎯 设计原则

### ✅ 必须遵守

- **结构同构性**: 深层机制对应，而非表面叠加
- **逻辑自洽**: 疯狂想法，严密逻辑
- **商业闭环**: 必须说明如何赚钱和护城河
- **具体可执行**: 产品形态和流程清晰

### ❌ 严格禁止

- **简单加法**: Coffee + Quantum ≠ Quantum Coffee
- **伪科学**: 用思维模型重构，而非术语忽悠
- **线性外推**: 追求范式转换，而非更快更强
- **缺乏论证**: 每个创新点都要有理据
